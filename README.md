# Sistem Manajemen Data Mahasiswa

Aplikasi UAS berbasis web menggunakan Python dan Streamlit.

## Cara Menjalankan
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Fitur
- CRUD data mahasiswa
- File I/O CSV
- OOP: class, object, encapsulation, inheritance, polymorphism
- Regex validation
- Try-except
- Linear Search dan Binary Search
- Bubble Sort dan Merge Sort
- IPK skala 0.00 - 4.00
- Dashboard modern
